# 问题、方案与证据

## 1. 单位解析与歧义

现象：0.5公里可以被首数字法误读为0.5m；附近不可计算。定位：弱基线的固定单位假设与未归一输入。方案：自由文本截取、纯模型、结构化Schema三选；采用规则/模型输出统一Schema并要求确认。代码：parser.py、schema.py。实测：test_units_and_example把0.5公里归一500米；test_clarification拒绝模糊和未消费条件。局限：离线中文数字距离不支持；真实LLM未验证。

## 2. CRS与像元错位

现象：缺CRS仍赋4326可能制造错误距离；同数组位置并不等于同坐标。证据：原get_buff.py曾有set_crs默认；GIS测试构造混合CRS与5m栅格错位。备选：自动猜测、自动重采样、显式预检。取舍：缺CRS直接拒绝，所有向量对齐明确米制CRS，栅格严格对齐。代码：gis.py。实测：mixed_crs对称差面积<0.01m²；raster错位/分辨率测试通过；缺CRS运行FAILED。局限：当前只支持局部合成区域，不是通用投影引擎。

## 3. 结果可信性与可解释性

现象：地图可生成并不证明推荐满足约束，也不证明得分正确。定位：缺独立数值验收。方案：模型描述、仅输出几何、导出原始指标并独立验证；选择最后一种。代码：selection.py validate_results和rank_candidates。实测：篡改原始距离、得分均被回归测试拒绝；44个构造用例中56个Top-K候选硬约束违规0。局限：验证采用相同几何库，不是独立GIS供应商交叉认证，250m采样也非全局最优。

## 4. Agent控制边界

现象：原自由工具与eval接口有执行风险，重复工具调用缺有效证据。备选：额外Prompt约束、工具白名单状态机、复杂多Agent。选择状态机固定单工具计划。代码：workflow.py、gis.py；旧eval已禁用。实测：确认前不执行、每run隔离、原任意open-folder路由404；模型超时/坏输出安全澄清。局限：没有实测原ReAct重复调用率，不宣称降低某百分比；尚无跨进程恢复。
