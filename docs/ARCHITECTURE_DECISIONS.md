# 架构决策

| 选项 | 选择理由 | 代价 | 验证方式 |
|---|---|---|---|
| 包裹原Agent / 独立v2包 | 原入口TSD不可执行；保留app与原main.py，geosite隔离导入 | 不是原ReAct完整兼容，旧栅格等功能未迁移 | 导入main_web；离线测试；BASELINE记录旧入口失败 |
| LangGraph / 明确状态机 | 有限单工具计划，无收益支撑新增框架 | 不支持任意动态工具链、跨进程恢复 | test_workflow检查完整状态序列和确认门 |
| 真实LLM / 规则模式 | 默认零API离线；可选Schema模型仅解析 | 离线语法窄；实网模型未验证 | test_model模拟合法/拒答/坏JSON/超时；共同GIS结果相同 |
| 通用自动投影 / 明确局部米制场景 | 合成数据明确32650；所有输入统一到同一CRS，缺失拒绝 | 不能直接扩展全球场景；10km范围限制非通用投影选择器 | mixed CRS误差测试；feet/geographic拒绝 |
| 全连续搜索 / 网格中心 | 250m中心可复算，成本上限1600点 | 会漏掉窄小可行区，空网格不等于空连续区域 | 输出网格间距、筛选数量、精确距离 |
| 候选min-max / 固定尺度评分 | 1/(1+d/1000)，权重非负后归一 | 1000m只是演示尺度，业务适用性未验证 | rank_candidates从导出原始指标复算；改变权重测试 |
| Folium在线底图 / 离线SVG | 无外部地图CDN，断网也能打开，GeoJSON单独WGS84导出 | 无底图、平移缩放和复杂空间交互 | 浏览器目检地图；GeoJSON坐标和要素计数测试 |
| 自动重采样 / 严格栅格对齐 | 先拒绝CRS/仿射/分辨率不一致，NoData掩膜传播 | 用户须明确提供重采样策略，当前不自动修复 | raster错位与分辨率测试 |
| 任意eval / 固定栅格求和 | 不接受表达式，旧eval禁用 | 旧表达式能力暂停 | 源码扫描；raster_sum掩膜测试 |
| 重前端 / 同源FastAPI页面 | 复用原Web入口，无构建工具 | 参数JSON编辑不适合最终非GIS用户；无实时进度 | test_web及浏览器输入确认闭环 |

P2（MCP/RAG/多Agent）本轮跳过：没有跨客户端工具复用、可信政策语料或单Agent职责冲突的实证需求。
