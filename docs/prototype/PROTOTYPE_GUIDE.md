# 五页交互原型与演示指南

实现：ui/retail_app.py，Streamlit 原型直接作为MVP前端。没有生成 Figma 文件。统一深青侧栏、浅灰背景、白色指标卡、绿色主操作；黄色提示用于模拟假设和风险。

| 页面 | 主要展示 | 可执行交互 | 状态传递 |
| --- | --- | --- | --- |
| 经营分析总览 | 品牌/城市、时间窗口、四项KPI、趋势、营业额分布、问题输入、最近任务 | 调整总览窗口、解析需求、进入诊断 | AnalysisRequest写入当前工作流，旧分析清空 |

## 启动

在 D:/Geogpt/GeoGPT 执行：

```powershell
.venv/Scripts/python -m streamlit run ui/retail_app.py --server.address 127.0.0.1 --server.port 8501 --browser.gatherUsageStats false
```

浏览器访问 http://127.0.0.1:8501。五页通过左侧工作空间导航直接切换。未产生分析前，后续页面显示空态与下一步说明。

## 约三分钟的作品集演示路径

1. 总览指出CoffeeLab和所有GIS图层均为模拟；展示窗口和趋势。
2. 使用默认核心问题，点击“解析需求”，查看结构化参数，再进入经营诊断。
3. 说明利润率的汇总口径和窗口起点满12个月的成熟定义；勾选确认，执行分析。
4. 查看排名和门店详情；展示优秀样本与其余样本的差异，指出人为注入的办公商圈规律不能作为真实行业结论。
5. 点击制定策略，解释待验证建议与硬约束的区别。修改权重使合计不为100%，观察按钮禁用；恢复100%，确认并筛选。
6. 进入候选商圈，查看真实计算的三个结果，下拉/地图点选，说明评分、重叠与核查项。若约束收紧后无结果，返回策略调整。
7. 打开记录与报告，查看工具耗时和确认快照，下载报告。

## 状态与错误演示

- 输入“分析利润率”：缺少时间范围，解析要求澄清。
- 删除店型展示选择：排名视图为空，但已执行分析仍保留。
- 权重合计80%：显示错误且禁止提交。
- 距现有店至少20000米：返回空结果与排除计数，不拼凑三条推荐。
- 选择在线模式但未配置环境变量：提示配置问题，不伪装模型执行成功。
- 工具数据缺失/非法CRS：自动化故障注入测试覆盖，页面显示失败状态。

## 地图与离线范围

分析、评分、报告、图表均可本地计算。Folium的Leaflet前端首次加载依赖CDN；公开底图默认关闭，需要用户主动勾选并联网。不把可运行的离线计算宣称为所有地图资源均已离线打包。断网时展开“本地坐标视图”，使用候选下拉和散点图复核结果。

## 交互验证边界

AppTest覆盖五页导航、确认按钮、店型过滤、权重校验、筛选、候选选择和报告流。AppTest不运行第三方地图JavaScript，不能据此宣称地图点击/资源加载完成浏览器验收。实际浏览器检查情况以测试报告为准。
