# 页面与状态说明

真实UI实现：geosite/ui.html；服务：geosite/web.py。已在本地浏览器实际点击解析、勾选确认并执行，看到COMPLETED、3个推荐及合成SVG地图。未持久化截图，不把设计图冒充实测截图。

| 区域 | 字段/组件 | 行为与反馈 |
|---|---|---|
| 任务输入 | 需求文本、数据说明、解析、单约束/澄清示例 | 限2000字；只支持演示区域；解析时清除确认 |
| 需求确认 | JSON文本域、confirmed勾选、执行/重新排序 | 编辑距离米、within/outside、偏好列表和权重；未勾选提示确认 |
| 执行状态 | aria-live状态、Trace展开 | 执行中禁用按钮；完成展示完整Trace；错误提供重试提示 |
| 结果分析 | 空态、下载链接、排名/距离/分项评分/约束表、地图iframe | 空网格有明确文案；推荐以紫色高亮；JSON/CSV/GeoJSON/HTML/MD导出 |

待改进：将JSON编辑换成字段表单；长JSON表格可读性；异步进度/取消；地图交互；移动端与屏幕阅读器专项测试。本轮仅桌面浏览器功能和视觉核验。
