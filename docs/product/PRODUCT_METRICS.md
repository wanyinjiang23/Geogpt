# 指标与采集口径

北极星候选指标（产品设想）：每周完成且可复算的有效选址决策数。当前没有真实用户，不能报告该指标的业务数值。

| 指标 | 分子/分母或定义 | 当前采集 |
|---|---|---|
| 完整任务成功率 | 满足用例所有断言数/所有构造用例数 | evals/run_eval，含预期拒绝与澄清的正确行为 |
| 业务执行完成率 | COMPLETED业务任务/有效业务请求 | 待真实使用埋点，不与上述评测通过率混用 |
| 字段解析准确率 | 标注顶层字段精确匹配数/标注字段数 | 已实现；约束列表整体为一字段，非逐槽位评分 |
| 硬约束违规率 | 违反至少一个硬条件的Top-K候选/Top-K总数 | 由导出坐标独立复算距离 |
| 空结果识别 | 返回empty且确无网格候选/标注空案例 | 已实现，不能推断连续空间无解 |
| 工具有效率 | 按用例规则必要的白名单调用/总调用 | 当前只含单工具固定计划 |
| 澄清率 | NEEDS_CLARIFICATION请求/总请求 | Trace可采集；正常参数确认与语义缺失须分开，当前未汇总 |
| 完成耗时 | 收到请求至完成墙钟时间 | Trace elapsed_ms；评测中位数包括工件写入 |
| API成本/token | 服务商实测使用量×价格 / usage | 未接真实API，报告null，不写零成本模型 |
| 用户可用性 | 首次独立完成率、确认后修改率、满意度 | 待招募真实用户验证，不能虚构访谈 |

当前evals/results/summary.json是小型合成集工程验收，不代表上线收益。
